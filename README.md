# thai-minh-webpack-3
Website thaiminhgroup.vn use webpack tool to build 

### Install [nvm for Windows](https://github.com/coreybutler/nvm-windows) and then in an elevated PowerShell / CMD run:
+ `nvm install 14`
+ `nvm use 14.21.3`
+ Verify with: `node -v`

### Installing
Note: Delete **node_modules** and the lockfile (*package-lock.json* or *yarn.lock*).

Install dependencies and start using [yarn](https://yarnpkg.com):

```CLI
yarn install --verbose`
yarn start
```

Or via [npm](https://www.npmjs.com/):

```CLI
npm install --verbose`
npm run dev
```

### Production build

You can generate an optimized distribution bundle. To do this run the command:

```CLI
yarn build
yarn preview
```
Or

```CLI
npm run build
npm run preview
```
